# Data and publication boundaries

The current tree contains public benchmark inputs, public benchmark outputs explicitly approved for transfer, and fabricated unit-test examples. Private document samples and all derived pilot outcomes are excluded, including aggregate field counts, evidence counts, pilot comparisons, presentations and institutional planning notes.

Public case families include ChartQA, public document-layout/table/image sources recorded in the pack receipt, CUAD and ContractNLI. The pack's manifests and receipt are authoritative for included files. Refer to publisher notices; access on the web is not a blanket license for commercial redistribution. Original spreadsheet support is a planned application, not an evaluated native-Excel feature.

Large public images are stored in Git LFS. Runtime databases and new raw model responses stay local. Public row exports remain separate from aggregate presentation data. Never add keys, service URLs or deployment metadata that identifies a private environment.

The privacy gate scans the current tracked/project tree and validates prohibited paths and identifiers. The reachable histories of all 14 personal-repository branches were scrubbed separately on 26 October 2026. See [resync instructions](RESYNC.md). Other clones, host caches, unreachable objects, Git LFS storage and earlier downloads are outside that guarantee. Review remaining publication risk before making the repository public.
