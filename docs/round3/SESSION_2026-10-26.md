## 6. Errors met and how each was fixed

- Permission classifier refused to kill another session's vLLM server and an orphaned Ollama `llama-server`; Tayler ran the kill herself, and `ollama stop <model>` clears orphans. Rule: never kill port 8001 except through the driver's own reclaim.
- Byte-based context guard rejected 32 of 60 legal cases: replaced by the measured-token prefill guard.
- gpt-oss residency check failed on a stalled Ollama runner: residency moved before the loop, IN_FLIGHT markers cleared (no scored request had been sent), rerun succeeded.
- Driver repo path wrong (results landed under `benchmarks/`): fixed to the repo root.
- PaddleOCR tables scored zero: OTSL output discovered by probe, `otsl_to_grid` added, raw head stored.
- WSL jobs died with the shell: run from background Bash with `MSYS_NO_PATHCONV=1`; CRLF in a Windows-written name list broke tar (`tr -d '\r'`).
- Recursive `base_task` after a global replace: fixed. Codex's test broke on `run_case` arity: fixed with module-level run options.
- No unused English OmniDocBench tables (all 219 used): `table_confirm3` moved to FinTabNet.c, pre-registration amended before any table run.
- Round 3b: the 16,384 budget arm was rejected by every server (served context 16,384, HTTP 400) and Parse multipass died on a missing `import os`. Both purged and rerun by round 3c (recovery arm at 12,288). Pre-registration amended.
- Parse venv install ran before the download finished: reinstalled from the local copy.
- 7B replay agreement summary crashed on failed rows stored as JSON null after all cases were scored: guarded, `--summary-only` added, summary recomputed without model calls.

## 7. Audit verdict in one paragraph

The vision-model comparison is a controlled, pre-registered, reproducible study on public data. The round-3 parser result is a strong lead, closable to a defensible claim by round 3b (fresh sets, equal budget, official pipelines, intervals). The legal track ranks configurations until Qwen3 32B finishes the 60-document contrast. Domain documents, a field-bound numeric metric with false positives, a clustered acceptance bound for the 99% bar, and packet-level tasks remain the honest boundary; the coverage matrix in `AUDIT.md` shows which public proxy stood in for each use-case need.
